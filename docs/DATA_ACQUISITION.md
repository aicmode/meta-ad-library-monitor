# Meta Ad Library データ取得方式の技術検証

実施日: 2026-08-21 / 対象国: 日本 (JP) / 対象: 一般商用広告

MVP実装前に、「Meta Ad Libraryから必要な広告情報を現実的かつ安定して取得できるか」を実際に検証した記録です。推測ではなく、実行結果に基づいています。

---

## 結論

| 方式 | 日本の一般商用広告 | 採用 |
|---|---|---|
| Meta公式 Ad Library API (Graph API `ads_archive`) | **取得不可** | ✗ |
| 公開Webの広告ライブラリ + Playwright | **取得可能（全必須項目100%）** | ✓ |

日本向けの一般商用広告は公式APIの対象範囲外であることが、Meta公式ドキュメントと実測の両方で確認されました。そのためMVPではPlaywrightによる公開ページの取得方式を採用しています。

---

## 1. 公式API (`ads_archive`) の検証

### 1.1 仕様上の制約

Meta公式ドキュメント（`developers.facebook.com/docs/graph-api/reference/ads_archive/`）に以下の明記があります。

> **"Ads that did not reach any location in the EU will only return if they are about social issues, elections or politics."**
> （EU圏に配信されなかった広告は、社会問題・選挙・政治に関する広告である場合のみ返却される）

つまり：

- **EU圏に配信された広告** → 全ジャンル（商用含む）が取得可能（DSA / デジタルサービス法に基づく義務）
- **EU圏外に配信された広告** → 社会問題・選挙・政治広告のみ

日本のみをターゲットとした看護・美容・不動産・人材・EC等の一般商用広告は、**この条件で完全に対象外**になります。

`ad_type` パラメータが受け付ける値も `ALL` / `EMPLOYMENT_ADS` / `FINANCIAL_PRODUCTS_AND_SERVICES_ADS` / `HOUSING_ADS` / `POLITICAL_AND_ISSUE_ADS` のみで、一般商用広告を指す区分が存在しません。

### 1.2 実測

```
GET https://graph.facebook.com/v23.0/ads_archive
    ?ad_reached_countries=['JP']&search_terms=看護&fields=id,page_name,...
→ HTTP 500
  {"error":{"message":"An unknown error has occurred.","type":"OAuthException","code":1}}
```

アクセストークン無しでは当然エラーになります。加えて公式APIの利用には、Meta開発者アカウント・アプリ作成・**本人確認（身分証明書の提出）**・居住国確認が必要で、個人が即座に利用開始できるものではありません。

### 1.3 判定

**日本の一般商用広告の監視という本ツールの用途では、公式APIは利用できません。** 仮にトークンを取得しても、返るのは政治・社会問題広告のみです。

## 2. Playwright方式の検証

### 2.1 前提：素のHTTPは不可

```
curl -A "Mozilla/5.0 ..." "https://www.facebook.com/ads/library/?...country=JP&q=看護"
→ HTTP 403 (481 bytes)
```

広告ライブラリは結果一覧をクライアントサイドで描画するため、実ブラウザが必要です。

### 2.2 実ブラウザ（Chromium / Playwright）

ログインなしの公開状態で、広告カードが完全に描画されることを確認しました。

```
STATUS 403  ← シェルのステータスは403だが、コンテンツは正常に描画される
TITLE: 広告ライブラリ
検索結果: 約8,200件
  ライブラリID: 1003740095417676
  掲載開始日: 2026/05/03
  株式会社グロースデザイン / スポンサー広告 / 広告本文...
```

### 2.3 取得できた項目（実測）

`view_all_page_id` 指定の広告主1件に対する実行結果：

```
取得: 6件 (12.2s)   Meta表示件数: 6

広告識別子 (Library ID)     6/6 (100%)
広告主名                    6/6 (100%)
広告本文                    6/6 (100%)
掲載開始日                  6/6 (100%)
スナップショットURL          6/6 (100%)
リンク先URL                 6/6 (100%)
画像あり                    5/6
動画あり                    1/6
```

要求された必須項目はすべて取得可能です。

| 項目 | 取得可否 | 備考 |
|---|---|---|
| 広告を識別できる値 | ✓ | Metaの「ライブラリID」。再取得しても不変で、差分判定の主キーとして利用 |
| 広告主名 | ✓ | カード上の表示名 |
| 広告本文 | ✓ | 稀に本文なしのクリエイティブあり（実測 66件中1件） |
| 掲載開始日 | ✓ | "Started running on Apr 20, 2026" をISO日付へ変換 |
| スナップショットURL | ✓ | `https://www.facebook.com/ads/library/?id=<ライブラリID>` として構成 |
| 広告画像 | ✓ | `scontent.*.fbcdn.net` のURL。ブラウザで表示可能 |
| 広告動画 | △ | 動画の存在とポスター画像は取得可。**mp4本体は再生不可**（後述） |
| リンク先URL | ✓ | `l.facebook.com` のリダイレクタを解除して取得 |
| アクティブ状態 | ✓ | Active / Inactive |
| 広告主ページID | △ | 広告主指定URLでは確実。キーワード検索では推定値 |
| インプレッション数・費用 | ✗ | 一般商用広告では非公開（Web UI自体に表示されない） |
| ターゲティング情報 | ✗ | 同上 |

### 2.4 取得できなかった項目とその理由

- **広告動画の再生**: 動画URL（`video-*.fbcdn.net`）は短時間で失効する署名付きURLで、外部からのホットリンク再生を拒否します。QAで実際に4xxを確認しました。**代替として動画のポスター画像を保存・表示し、再生は「元広告を開く」で広告ライブラリへ誘導する方式にしています。**
- **インプレッション・費用・ターゲティング**: 政治・社会問題広告にのみ開示される項目で、一般商用広告では広告ライブラリ自体が表示しません。取得元が存在しないため実装していません。

### 2.5 対応URL形式

ユーザーがブラウザからコピーしたURLをそのまま使えるよう、2形式に対応しています。

- 広告主指定: `?view_all_page_id=<id>&search_type=page` — 件数が安定し、監視に最適
- キーワード検索: `?q=<語>&search_type=keyword_unordered` — 複数の広告主が混在する

### 2.6 ページネーション

スクロールによる追加読み込みを確認（25件 → 75件）。既定では1回の取得につき最大60件、スクロール6回で打ち切ります。

---

## 3. アクセス方針

本ツールは以下を **行いません**。

- ログイン、Cookieの偽装、認証情報の使用
- CAPTCHAの回避・自動突破
- アクセス制限・Bot対策の回避
- レート制限を超える高頻度アクセス

取得しているのは、ログアウト状態の一般利用者が閲覧できる公開ページのみです。制限ページやログイン要求が返された場合は、回避を試みずエラーとして報告します。スクロール間隔（2.5秒）など、意図的に低負荷な間隔を設けています。

---

## 4. 安定性に関する注意（重要）

この取得方式には以下の構造的リスクがあります。運用上、必ず認識してください。

1. **公式APIではないため、Meta側の仕様変更で動作しなくなる可能性があります。** 広告ライブラリのDOM構造が変われば、抽出ロジックの修正が必要です。
2. 広告カードには安定したCSSクラス名がないため、「Library ID」というラベル文字列を起点にDOMを遡る方式を採っています。ラベルの表記が変わると影響を受けます。
3. UIロケールを `en-US` に固定して日付とラベルを解析しています。これによりMeta側の日本語表記変更の影響は受けにくくしていますが、英語表記の変更には影響されます。
4. 高頻度アクセスや大量の監視対象を並行実行すると、Metaからアクセス制限を受ける可能性があります。
5. Metaの利用規約は自動収集を制限しています。**業務利用の際は、自組織の法務・コンプライアンス方針に照らして判断してください。** 本ツールは技術的な検証結果を提供するものであり、利用の適法性を保証するものではありません。

継続運用する場合は、`npm run validate:fetch` を定期的に実行し、取得率が落ちていないかを監視することを推奨します。
